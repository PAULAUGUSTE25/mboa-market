🎬 SCÉNARIO DE DÉMONSTRATION
═══════════════════════════════════════════════════════════

1. CONNEXION (1 min)
   - Montrer la page de connexion
   - Se connecter avec le compte démo
   - Expliquer la sécurité (JWT, bcrypt)

2. FEED (2 min)
   - Parcourir les 20 annonces
   - Montrer les filtres (Agriculture/Élevage)
   - Tester la recherche
   - Cliquer sur "J'aime"

3. CRÉATION D'ANNONCE (2 min)
   - Cliquer sur le bouton "+"
   - Remplir le formulaire
   - Ajouter une image
   - Publier

4. MESSAGERIE (1 min)
   - Cliquer sur "Contacter le vendeur"
   - Envoyer un message
   - Montrer la réponse automatique

5. PROFIL (30s)
   - Afficher les informations
   - Montrer le bouton déconnexion
